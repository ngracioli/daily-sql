# How To Add A Feature

Steps
1. Create a feature folder under `src/features/<feature-name>`.
2. Add `ui/`, `model/`, `api/` subfolders as needed.
3. Place feature-specific pages or routes inside the feature folder if possible.
4. Add a `README.md` inside the feature folder describing purpose and public exports.
5. Add tests and update docs/guides and code-organization if the feature requires special instructions.
